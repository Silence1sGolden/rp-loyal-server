### Структура папок и файлов

src/ — главная папка для всего вашего кода.
src/app.js — файл настройки самого сервера Express.
src/server.js — точка запуска, которая включает сервер.
src/routes/ — папка для путей (например, user.routes.js).
src/controllers/ — папка для логики работы (например, user.controller.js).
src/models/ — папка для работы с базой данных (например, user.model.js).
src/middlewares/ — папка для проверки данных и прав (например, auth.middleware.js).
src/config/ — папка для настроек и подключения к базе данных (например, db.js).

### Как работают слои

- _Роуты_ ловят адрес страницы и передают задачу дальше.
- _Контроллеры_ делают саму работу: берут данные, вызывают базу и шлют ответ.
- _Модели_ описывают, как данные хранятся в базе.
- _Мидлвары_ проверяют пользователя до того, как он дойдет до контроллера.
